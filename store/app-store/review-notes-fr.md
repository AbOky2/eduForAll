# Notes pour la review Apple (brouillon)

- Application éducative pour enfants de 6–8 ans (CP1–CP2), en français.
- **Aucun compte requis** : le profil (prénom + avatar) est purement local.
- **Aucune connexion réseau** : l'app est conçue offline-first ; vous pouvez
  la tester intégralement en mode avion.
- L'espace « Parents » est protégé par une question de multiplication
  (parent gate) ; il donne accès à la progression, aux réglages et à la
  réinitialisation.
- Le bouton « Partager la progression » utilise uniquement la feuille de
  partage iOS avec un texte visible par le parent.
- Aucune collecte de données, aucun SDK tiers, aucune publicité, aucun achat.
