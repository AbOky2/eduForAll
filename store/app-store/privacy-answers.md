# Réponses « App Privacy » App Store Connect (brouillon)

**Data collection** : *Data Not Collected* — l'application ne collecte aucune
donnée. Justification par catégorie :

| Catégorie Apple | Réponse | Note |
|---|---|---|
| Contact Info / Identifiers / Location | Non | Aucun compte, aucun réseau |
| Health, Financial, Browsing, Search | Non | — |
| User Content | Non collecté | Prénom/avatar/progression stockés localement, jamais transmis |
| Usage Data / Diagnostics | Non | Pas d'analytics ; diagnostic local exporté volontairement par le parent via la feuille de partage |
| Tracking | Non | Aucun tracking, aucun SDK tiers |

**Kids Category** : app éducative 6–8 ans ; parent gate présent ; aucun lien
externe dans l'espace enfant ; aucune publicité.
