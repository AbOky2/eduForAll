# Classification d'âge (brouillon)

Questionnaire Apple : toutes les réponses « Non » (violence, contenu sexuel,
jeux d'argent, horreur, substances, etc.). Résultat attendu : **4+**.

Catégorie principale : Éducation. Catégorie secondaire : Enfants (6–8 ans)
si le programme Kids est retenu — décision propriétaire
(docs/store-readiness.md).
