# Checklist programme Familles (brouillon)

- [x] Aucune publicité (aucun SDK publicitaire embarqué — gate automatisée)
- [x] Aucun achat intégré
- [x] Aucune collecte de données enfants (Data Safety : « aucune collecte »)
- [x] Aucun lien externe accessible depuis le parcours enfant
- [x] Actions sensibles derrière un parent gate
- [x] Contenu approprié (éducatif, sans violence)
- [x] Pas de connexion sociale, pas de chat, pas de contenu généré par autrui
- [ ] Politique de confidentialité hébergée sur URL publique (propriétaire)
- [ ] Déclarations Play Console signées par le propriétaire du compte
