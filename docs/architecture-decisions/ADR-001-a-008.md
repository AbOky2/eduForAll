# Registre des décisions d'architecture (ADR 001–008)

## ADR-001 — SQLite comme source de vérité
**Contexte** : progression durable d'enfants, offline, appareils modestes.
**Décision** : expo-sqlite + migrations versionnées append-only ; Zustand
réservé à l'état de session (profil actif, préférences chargées).
**Conséquences** : requêtes jointes efficaces (accueil, parent), reprise
fiable, testabilité par repositories.

## ADR-002 — Contenu bundlé validé, index en base
**Décision** : le manifeste JSON (généré, validé Zod) est la vérité du
contenu ; SQLite n'en garde qu'un index (titres, ordre, prérequis,
compétences) pour les jointures. Import transactionnel, idempotent par
`contentVersion`, jamais destructif pour la progression.

## ADR-003 — Machine d'état de leçon en reducer pur
**Décision** : pas de XState en V1 ; reducer TypeScript exhaustif, phases
explicites, transitions illégales ignorées par construction, testé sans
React. **Rejeté** : lib de state machine (dépendance non justifiée à cette
échelle).

## ADR-004 — Registry d'exercices typé
**Décision** : `Record<ExerciseType, Renderer>` — l'ajout d'un type casse la
compilation à chaque point de passage (schéma, évaluateur, registry). Type
inconnu au runtime → fallback explicite, jamais d'écran vide.

## ADR-005 — Expo Router exclusivement
**Décision** : aucun import `@react-navigation/*` direct ; groupes de routes
(onboarding/child/parent/settings/dev), guard de profil dans le layout child.

## ADR-006 — Audio placeholder sous gate
**Décision** : pipeline TTS reproductible pour développer sans studio ;
`placeholder: true` dans le manifeste audio et gate bloquante dans
`validate:release`. On ne prétend jamais que le build est publiable.

## ADR-007 — Bottom nav claire unifiée
**Décision** : la variante sombre de la maquette S15 n'est pas retenue ;
une seule nav claire à pill sable (cohérence + contraste). Cf.
`design-decisions.md` §1.

## ADR-008 — Polices en assets natifs
**Décision** : Quicksand + Plus Jakarta Sans embarquées via le plugin
expo-font (ressources natives, pas de chargement runtime ni de FOUT, zéro
réseau). Licences OFL conservées avec les fichiers.
